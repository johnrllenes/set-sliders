Understanding Set Theory with Set Sliders

Explore how sets organize elements and how visual overlays reveal subsets, unions, intersections, differences, and complements.

Universal Set (U)

The rectangular canvas that contains every element under consideration. Every circle or element you place lives inside U.

Example: U = {1, 2, 3, LOVE, AOI, DONUT, BOY, 35}
Sets & Elements (∈)

A set is a well-defined collection of distinct objects called elements. We write x ∈ A when element x is inside Set A.

Example: Set A = {1, 2, 3, LOVE}
Subsets (⊂) & Empty Set (∅)

If every element of Set B is also inside Set A, then B ⊂ A (B is a subset of A). A set with zero elements is the empty set { } or ∅.

Tip: Drag a smaller circle inside a larger circle on the canvas!

How To Use the Canvas

Quick guide to building sets, placing elements, and operating Set Sliders.

1. Add & Arrange Sets

Click + Add Set in the top bar to place circles inside the Universal Set (U). Drag any circle to move it, or drag its bottom-right perimeter dot to resize. Placing a smaller set fully inside a larger set automatically creates a subset (⊂).

2. Rename or Delete Sets

Click the top pill label on any set circle (e.g., Set A) to rename it or remove it from the board.

3. Create & Move Elements

Click + Add Element to add words, numbers, colored shapes, emojis, or pictures. Drag element chips into any region of your Venn diagram, or click ⋮ on a chip to edit or delete it.

4. Use & Stack Set Sliders

Expand SET SLIDERS at the bottom and click any operation card (Set, Union, Intersection, Difference, Symmetrical Diff., or Complement) to mask the board. Click an active card again (or press ✕) to turn it off, or stack multiple sliders together.

5. Board Size, Zoom & Saving

Switch between Small, Normal, and Huge canvas presets or use − / + zoom controls. Click the blue Save diskette button to store up to 3 browser slots or download a .json file.

6. Keyboard Shortcuts

Click a set or element to select it, then use Arrow Keys to nudge its position (hold Shift for larger steps) and + / − to resize a selected set.

About Set Sliders

Description

Set Sliders is an interactive digital manipulative learning material designed to easily teach Grade 7 students the concepts and operations of Set Theory—including sets, subsets (⊂), union (∪), intersection (∩), difference (−), symmetrical difference (Δ), and complement (')—through hands-on visual overlays over a Universal Set (U).
